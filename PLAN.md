# Sequence Studio — Plan

Native macOS video editor. Premiere Pro replacement with Premiere's editing logic and a cleaner,
Final-Cut-like look. Built first for a short-form (9:16) workflow, later open source under GPL-3.0.

## Platform
- macOS 26 Tahoe minimum, Apple Silicon only (dev machine: M1 Max). No cross-platform.
- Swift 6, SwiftUI for the shell, AppKit + Metal for timeline and monitors.
- AVFoundation, VideoToolbox, Metal, Core Image (sparingly), Core Text, Speech (SpeechAnalyzer), AudioToolbox.
- English everywhere: code, UI, docs.

## Interaction principles
- One window: Project/Bins, Source Monitor, Program Monitor, Timeline, Effect Controls.
- Premiere keyboard shortcuts (J/K/L, I/O, V, C, Q/W, B ripple, N roll, Y slip, S snapping, `,` `.` insert/overwrite).
- Everything keyframe-based, no nodes. Effect Controls works like After Effects: summary keyframes on collapsed rows,
  easing templates via right-click, relative multi-keyframe editing (see docs/UX.md). Drag & drop everywhere. Minimal menus.
- Layout: see "Panels" below.

## What it must feel like (Paul's priorities)
- **Speed of cutting beats everything.** Premiere's workflow and handling, Final Cut's clean, Apple-like look.
- **No magnetic timeline.** Classic tracks like Premiere. Ripple only when asked for (tool/shortcut).
- **Fewer clicks than Premiere.** Every common task gets a direct path with sensible defaults; no conversion steps.
  Example — captions: one button "Transcribe" → transcript editor opens in place → one button "Create captions"
  uses the default preset → captions are editable text layers right away (no "convert to graphics").
- **Easing must be excellent** (the weak spot in FCP, CapCut, DaVinci):
  per-keyframe interpolation (linear, hold, bezier), draggable bezier handles, value graph + speed graph
  in Effect Controls, easing presets (ease in/out, custom curves saved as presets), apply/copy easing to many
  keyframes at once, temporal and spatial (motion path) interpolation. Treat it as a core feature, not polish.
- Clean UI: native Apple controls wherever they fit (saves time, looks right). Custom only where needed
  (timeline, monitors, keyframe graph). Little chrome, no clutter.

## V1 scope
1. Import: iPhone HEVC (SDR + HDR/HLG), Sony S-Log3/S-Gamut3.Cine (currently XAVC H.264 4K, LPCM audio), mixed in one project.
2. Multiple sequences per project, free resolution/frame rate/aspect. Multitrack video + audio.
3. Color per clip: .cube LUT + basic correction (WB, exposure, contrast, highlights/shadows, saturation).
   Correct color management: Log/HLG input transforms, HDR→SDR, Rec.709 export tagged 1-1-1, viewer matches QuickTime.
   Scopes (waveform, vectorscope). Color page (second page, Final Cut-style color wheels), see docs/UX.md.
4. Editing: trim, ripple, roll, slip, snapping, J/L cuts, move, smooth scrubbing.
5. Audio: clip/track volume (keyframable), per-track presets (multiband compressor + light denoise).
6. Keyframes: position, scale, rotation, opacity with easing; keyframe editor in Effect Controls.
7. Effect: rounded corners.
8. Nested sequences.
9. Text layers, keyframable, user templates to drag in. Library panel: disk folders (thumbnails, search, favorites, audio preview) plus own presets
   (text templates, animated text templates in own format, effect/easing/caption presets). Late in V1, with text templates.
10. Captions: on-device German transcription, transcript editor, caption style preset + animation preset applied to all captions.
11. Export: H.264/HEVC (ProRes optional), social presets. Show Details with full settings (incl. loudness normalisation, sidecar .srt), background queue.
12. Undo/redo, autosave, robust project format.
13. Export several sequences of a project in one go (queue).

Later: Magic Mask (Vision segmentation / SAM 2 via Core ML), proxies, more codecs/effects/audio tools.
Non-goals: AI editing, auto-edits, cross-platform.

## Architecture
Own data model is the single source of truth; own Metal renderer draws every frame.
AVFoundation supplies decoding, clock and audio. Engine behind protocols so decode/clock can be swapped.

Swift packages (`Packages/`), app target in `App/`, project generated by XcodeGen (`project.yml`):

| Module | Contents | Depends on |
|---|---|---|
| `SSCore` | Project, Sequence, Track, Clip, KeyframeTrack, rational time, edit operations, undo, project file | — |
| `SSMedia` | Import, metadata, color space detection, thumbnails, waveforms | SSCore |
| `SSRender` | Metal compositor, color pipeline, effects, text | SSCore |
| `SSPlayback` | Clock, scrubbing, frame cache, audio graph | SSCore, SSMedia, SSRender |
| `SSExport` | AVAssetWriter using the same renderer | SSRender, SSPlayback |
| `SSTranscribe` | SpeechAnalyzer, transcript model, caption generation | SSCore |
| `App` | SwiftUI shell, AppKit timeline/monitors, panels, shortcuts | all |

Key decisions:
- Time: rational (Int64 value / Int32 timescale), never Double. Sequences are frame-based; sources keep their own timebase. VFR iPhone footage maps to the sequence grid.
- Model: value types. Undo/redo = model snapshots (copy-on-write), not NSUndoManager closures.
- Rendering: per frame, evaluate model → layer list (transform, keyframes, color, effects) → Metal compositor in half float. Nesting = evaluating a sequence as a source (recursive).
- Color: linear working space. S-Log3/S-Gamut3.Cine via math, HLG/709 via tags. Per clip: LUT slot + basic correction. Export Rec.709 tagged 1-1-1; Program Monitor ColorSync-managed so it looks like QuickTime/social apps (no gamma-shift workaround LUT).
- Project file: package directory with versioned JSON; media referenced by path + bookmark + fingerprint (relink). Autosave snapshots inside.
- Timeline: custom AppKit view (layer/Metal drawing), not SwiftUI.
- Audio: Apple's built-in AUMultiBandCompressor per track; denoise via RNNoise (BSD).
- Engine route decided by the Phase 0 spike: hybrid (AVComposition + custom compositor calling our renderer) vs own VideoToolbox decode path with frame cache. Renderer stays the same either way.

## Panels
Layout is stored as a tree (splits → tab groups → panels) from day one, so any later docking mode needs no rewrite.
- Phase 2: two built-in workspaces (Editing – PC, Editing – MacBook) switchable from a menu; resizable splits, show/hide panels.
  Default layout and panel contents: docs/UX.md.
- Phase 9: tab groups with drag-to-dock (Premiere-style), custom saved workspaces, per-screen-setup workspaces. Floating windows optional afterwards.

## Phases
0. Setup + spike: XcodeGen, build/test scripts, agents. Spike measures decode + scrub on M1 Max with Sony S-Log3 and iPhone HLG → engine decision.
0b. UX plan (`docs/UX.md`): window layout, every panel's contents, shortcuts, the core flows step by step
   (import → cut → color → keyframes → captions → export) with click counts vs. Premiere. Basis for Figma.
1. SSCore headless: model, time, trim/ripple/roll/slip, snapping logic, linked A/V, undo, project file. Tests first.
2. Playback + timeline UI: monitors, J/K/L, scrubbing, tools, drag & drop, insert/overwrite, basic import/bins. Figma design of the shell before this phase.
3. Color + export: pipeline, LUT, basic correction, H.264/HEVC export with social presets (early, to verify gamma in QuickTime).
4. Keyframes: Effect Controls, keyframe editor, easing, transform, opacity, rounded corners.
5. Audio: volume + keyframes, track presets, waveforms, J/L cuts polish.
6. Nesting + multiple sequences.
7. Text + templates.
8. Captions.
9. Stability + release: crash recovery, relink, performance, panel docking, open-source prep.
