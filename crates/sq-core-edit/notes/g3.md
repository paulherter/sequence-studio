## Notes / deviations
- `History` takes `limit`/depths as `usize` (Swift `Int`, never negative in use); `commit` has an infallible and a `try_commit` form for Swift's
  `rethrows`; the `lastKey` `didSet` is `set_last_key` (every assignment of nil clears the held steps, like Swift).
- Static Swift members that share a name with an instance member get a suffix: `source_edit_placement_from_marks`, `drag_marked_range_part`.
- Ids that Swift draws with `UUID()` come from an `IdSource` argument (`add_source_marker`, `translated_items`, `replace_with_sequence`,
  `grade_from_previous_clip`, `source_timeline`, `color_source_file_view`).
- `Timeline::duration()` is computed on every call; `mark_in_at`/`drag_marked_range` call it as often as Swift does.
