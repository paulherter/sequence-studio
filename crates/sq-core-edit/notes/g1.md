## Design
- `magnetic_edit` takes `(MagneticScope, &mut dyn IdSource, closure)`; the closure gets `(&mut Timeline, &mut dyn IdSource)` so a
  verb borrows the id source once. `MagneticScope` is Swift's four default arguments (`involving`, `local`, `stay`, `orphans`).
- Private Swift helpers are free functions; internal ones used by other modules are `#[doc(hidden)]` trait methods.
- `Dictionary`s in `magnetic_edit` are `BTreeMap`s; Swift's order only mattered for ties of `pinned` (sorted by start, stable).
- Shared test fixture of the Swift edit-core tests (`F`): `timeline_magnetic_ops::fixture` (test only).

## Swift quirks kept
- `replaceOnMainTrack` builds `Dictionary(uniqueKeysWithValues:)` by clip kind (traps when a linked group has two clips of one
  kind); Rust keeps the first.
- `NearProjectRelink.trailingMatch` uses `standardizedFileURL`; Rust joins the parts without resolving `.`/`..`.
