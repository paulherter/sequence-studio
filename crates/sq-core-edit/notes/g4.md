## Deviations and choices
- `ImportCommitPlan` takes an instant as a `Duration` since a caller-chosen monotonic origin (no `ContinuousClock` in Rust).
  `WorkPools::debug_line` takes the preference value; reading the setting is the caller's job.
- `ViewerZoom` has its own `Size`/`Rect` (no geometry type exists yet in `sq-core-time`).
- `DuckPreset::soft()/hard()/all()` are functions, not statics.
- `VisibleFirstQueue::next` is `pop_next` (clippy: `next` confuses with `Iterator::next`).
- `TimelineMarkersExt::add_marker` etc. take an `IdSource`; `sort_markers`/`new_marker` are crate-private helpers shared by
  cut_check and proposed_cuts.
- `CutCheck::analyze` takes `caption_bounds` as `Option<&dyn Fn(&CaptionItem) -> Option<NormRect>>`.
- Swift quirk kept: `toggleTarget` doc says Option-click on the only targeted track does nothing, but the code retargets the
  whole kind; the code is ported.
