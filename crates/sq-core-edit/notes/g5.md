# Grouping and title templates (rs/3-groupcore)

- `grouping.rs` ports Grouping.swift (`group`, `ungroup`, `unnest`, `prune_unused_groups`, Group Transform effect helpers).
  `ungroup`, `unnest` and `group` take an `IdSource` (Swift calls `UUID()`). `Bin::prune` in sq-core-model is now `pub`.
  Not ported here: the render tests of GroupingTests.swift that need `videoLayers`, `ProjectFile` or `SequenceConform`
  (the group stage math itself is tested in sq-core-effects), and the Adjustment Layer tests (`add_adjustment_clip` is in
  sq-core-effects; add them there).
- `title_template.rs` ports capture, detect_zones, apply, set slot and auto-detect. The type, `PayloadPath`, `set_slot` and
  the error enums are in sq-core-model (`title_template.rs`). `TemplateEditError` carries `EditError` or `TitleTemplateError`
  because the Swift functions throw both.
- Swift quirk kept: `copyWithFreshIDs()` of TitleTemplate.swift does not remap `gradeLink`; the reel fill variant
  (`copy_with_fresh_ids`, with a name) does. The template uses `copy_with_fresh_ids_mapped`, as Swift does.
- Payload JSON: serde_json writes sorted keys like JSONSerialization `.sortedKeys`, but numbers (`80.0` vs `80`) and `/`
  escaping can differ in text; the payload is read back by the same reader. Compare decoded content, not bytes.
- Not ported: the zone trim tests of TitleTemplateTests.swift (`innerTime`, `videoLayers`).
- `sq-core-project/project_template.rs` keeps its private `contains_item_ranges` / `contains_follow`; they now also exist as
  `Timeline` methods in sq-core-model.
