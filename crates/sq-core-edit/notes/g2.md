  the Fast Cut branch `fastCutSourceEdit` is the caller's until g1 lands).

`lift(range, tracks, ids)`, `lift_sparing(range, tracks, sparing, pruning, ids)`, `lift_clips(ids)` (by id),
`add_edit(t, tracks, ids)` / `add_edit_for_selection`, `mark_clip_range(t, tracks)` / `mark_clip_range_for_selection`,

## Waiting on / shortcuts to swap at the merge
- g1 (MagneticOps/Magnetic/Solo/AddTrack): `trim_edit` calls plain `ripple_trim` / `roll` (the Normal-mode path); a Fast Cut
  sequence must use `magnetic_ripple_trim` / `magnetic_roll`. `is_fast_cut` (timeline_move_track.rs), `push_track`
  (timeline_title_tracks.rs, Swift `addTrack`), `held_back_partners` (timeline_join_cuts.rs) are marked copies. `move_into_sync`
  refuses a main-track clip of a Fast Cut sequence with `Collision` (Swift moves its partners through `magneticEdit`).
- g4 (SyncOffsets): `move_into_sync` / `slip_into_sync` take the `sync_offsets()` map as an argument.
- g4 (ReplaceMedia, DropTargets): `fill_reel`, `pour_still` (need `replaceMedia`, `ReplacementMedia`), `source_patch_targets`
  takes `ensure_audio_track` as a closure (Swift `ensureAudioTrack(atOrdinal: 0)`); `copy_with_fresh_ids` needs
  `TitleTemplate.instantiated` (not in the model yet).
- `SafeZoneChoice`: `SafeZone`/`NormRect` (SafeZone.swift) are in no crate; not ported.
- `VariantOverride.frozen(atLocal:)`, `BakedEffect.frozen(atLocal:)` are private helpers in timeline_freeze_frame.rs
  (their files in the model are not ported); move them there later.
- `ResizeTransitionLayer` (parked by the effects crate for `trim`): the Swift `trim`/`roll` in this tree do not call it; nothing
  to port. Parked TransitionLayer/Transition edit-consistency tests (trim, roll, slip, move, paste, duplicate, moveInsert) can
  run now against these verbs.

## Swift quirks / deviations
- Swift iterates `Set`s (selection, links) in random order: `mark_overhang_range`, `link`, `unlink`, `nudge` use sorted order;
  only ties between equal candidates differ.
- `InterfaceScale.load/store` take and return the value; the settings store is the caller's. `didChange` is a plain string.
- `ProjectOpenRouting.message` returns `None` for the Rust-only `Encode`/`Io` variants of `ProjectFileError`.
- `TimelineClipboard` lanes are `usize`; its serde form uses camelCase keys.
