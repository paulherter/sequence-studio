## Decisions to record
- Swift extensions on model types are extension traits named after the Swift file (`ClipMasksExt`, `MaskInputsExt`,
  `PictureMaskTimelineExt`, ...), re-exported flat from `lib.rs`.
- `PerspectiveTilt.clamped` is `perspective_tilt::clamped` here. The model keeps its private copy
  (`clip_animation.rs: clamped_tilt`) because it cannot depend on this crate; both are the same 89 degree clamp.
- `StageTransform` (Swift `EffectTransformStage.swift`) lives in `stage_transform.rs` because the stabilizer plan
  produces it and the effects crate sits above this one: the effects port takes it from here.
- Kind strings (`MASK_INPUT_KINDS`, `IN_PLACE_KINDS`, the stage and track mask keys) are copied literals until the effects
  catalog constants exist (`// shortcut:` in the code).
- `ColorRangeKey.value` is `ColorRangeKeyExt` here (the model has the type, no logic). It belongs in the model or the
  color crate; the color crate must not define it a second time.
- `MatteRefine.morph` / `boxBlur` (plain path) are in `matte_refine.rs`; the effects port should reuse them for the rest
  of `MatteRefine`.
- `Angle view` of a nested clip (edit crate) is passed in as `AngleView` where Swift calls `angleView(of:)`
  (`magic_matte_needs`, `unlinked_picture_mask_count`).
- Swift `UUID()` inside logic: `ids: &mut dyn IdSource` parameters (`ClipMask::make*`, keys written by the track
  functions, `magic_click`, `pen_click`, `add_shape_mask_*`, `pasted_masks_with_map`).

## Swift behavior kept on purpose
- `largest_candidate` keeps the first of equal maxima like Swift's `max(by:)` (Rust's `max_by` keeps the last).
- Float `min(max(x, lo), hi)` became `clamp` (NaN passes through, as in Swift).
- `MagicSelection.cache_key` hashes the id bytes in UUID order and `f64`/`i64` as little endian (Swift hashes native bytes
  on little-endian Macs and Windows PCs).
- `Hashable` of float structs was dropped (`PartialEq` only).
- Float types follow Swift: mattes and logits `f32`, the rest `f64`; the LCGs of the tests are `u64` wrapping.
