## Decisions / deviations
- Platform backends are injected, not ported: `AutosaveStore.defaultBase`, `SessionMarker.startTime(of:)`,
  `RecoveryScanner.systemProcessCheck` (RecoveryScanner::new takes both closures), `CacheDiskPolicy.volumeSpace/standard`
  (`CacheDiskPolicy::new` takes the reader), `CrashReportStore.defaultDirectory`.
- Clock and ids as arguments: `now: Timestamp` on scan/scan_sessions/prune/write, `IdSource` for the autosave temp name.
- `RecoveryScanner<'a>`/`SessionMarker<'a>` borrow the `AutosaveStore` (it owns a boxed writer, not `Clone`).
- Date text helpers (`yyyyMMdd-HHmmss-SSS`, ISO 8601) are private copies in recovery.rs: sq-core-file keeps its twins
  `pub(crate)`. One home would be sq-core-time (make them public there).
- `FileWalk`: `is_package` is always false, links are not followed (`symlink_metadata`), order is by file name.
- `MediaFilterToken` day filter uses an injected `Calendar` trait; `FixedOffsetCalendar` has no daylight saving. Month outside
  1...12 gives no date (Foundation would roll over).
- `ForeignKeymapFile::read(data, plist)` takes the parsed plist (no plist parser in the workspace).
- `PremiereKysReader` reads XML with `sq_prproj_reader::fastxml` (new dependency line in this crate's Cargo.toml, Cargo.lock
  updated): UTF-8 only, no DTD.
- `MediaPathResolver::{file_name_of, folders_of, pick}` are associated fns (p2's relink planner waits for them).
  `delivery_target(platform)` free fn in sequence_format_presets (p2's project_template uses it).
- `RenderCacheStore` index.json keeps Swift's `lastUse` as seconds since 1970 (wire structs convert); `commit` returns an error
  for a missing segment file like Swift's `attributesOfItem`.
- `RelinkProposal.signals` is a hand-made bit set (`Signals`), no bitflags crate.
