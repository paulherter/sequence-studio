## Decisions to know
- Hidden catalog effect kinds are string literals (`vignette`, `brightnessContrast`, `blackAndWhite`, `noise`, `audio.gain`, `audio.eq`,
  `audio.parametricEQ`); swap for M-2 constants when they exist. `noise` is defined as `ClipEffect::NOISE_KIND` in effects_catalog.rs.
- `labels.rs` keeps a private `TEXT_GENERATOR = "text"` (Swift `GeneratorRef.text`); point it at M-1's constant when there is one.
- `Timeline::locate_clip` (private, clip_attachment.rs) is a read-only stand-in for Swift `Timeline.find`; M-5 can replace it.
- `normalizeBins` needs `titleTemplateInsides` (TitleTemplate.swift, no task): `Project::title_template_insides` in bin.rs.
- `Bin.modify` became `Bin::bin_mut` (returns the sub-bin). New ids (`new_bin`, `make_subclip`) come from an `IdSource`.
- Sort by name uses `sq_core_time::text::standard_compare` (documented ICU difference there).
- `trim_spaces` (project.rs) is Foundation's `.whitespaces` / `.whitespacesAndNewlines`; no shared home existed.
- Property setters that Swift writes as `x = v` are `set_*` methods (`set_channel_layout`, `set_timecode_start`, `set_pixel_aspect`, `set_edit_mode_stored`);
  `set_edit_mode_stored` does not derive attachments (Swift `setEditMode` does and waits).

## Deviations
- `MediaRef::status` uses `std::fs::metadata` (Swift `FileManager.attributesOfItem`); the modification date comes as unix seconds.
- Reading a project now repairs the bin tree (`normalize_bins`), so a file without `rootBin` gets its media and sequences filed: the old
  S-2 test expectation (empty root bin) changed to one child.
