## Naming decisions
- Swift extensions of `KeyframeTrack` (a `sq-core-time` type) are traits (`KeyframeTrackEditing`, `KeyframeGraph`, `KeyLoopBake`,
  `RovingKeys`, `KeyTimeScaling`, ...); `PropertyTrack`, `KeyframeSummary`, `EaseShape`, `AnimatedProperty<f64>` get inherent
  methods (same crate). The four-way `switch self` on `PropertyTrack` is the private macro `each_track!`.
- `KeyframesPair`, `SpeedHill`, `KeyVelocity` stay namespaces (unit structs with associated fns).
- Keyword and overload clashes: `loop` -> `loop_keys`, `KeyframeSummary.move` -> `move_key`, `apply(choice)` -> `apply_choice`,
  `EaseHandle(speedHandle:..)` and `EaseHandle(directedSpeed:..)` -> free fns `ease_handle_from_speed_handle`,
  `ease_handle_from_directed_speed`; `EasingCurve.bezierHandles` -> `keyframes_premiere::bezier_handles()`;
  `EasingCurve(shape:name:)` / `(presetPayload:..)` -> `easing_curve_from_shape` / `easing_curve_from_preset_payload`.
- Every `UUID()` is an `&mut dyn IdSource` argument (paste, split, aligning, edit, loop, bake, duplicates, spring bake).
- Swift default arguments became explicit: `SpeedHill::samples(shape, count)` + `default_samples` (49), `speed_overlay(samples, hue)`.
- Nested names are flat: `KeyframeClipboard.Key/.Track` -> `KeyframeClipboardKey/Track`, `SpeedHill.Sample` -> `SpeedHillSample`,
  `SpeedOverlayCurve.Key/.Handle` -> `SpeedOverlayKey/Handle`.
- `KeyInterpolationChoice::insert_key` casts through `std::any::Any` (stands in for Swift `as? KeyframeTrack<Vec2>`), so `V: 'static`.

## Swift quirks kept
- `KeyframeSummary.smoothSpatial` is documented as "Linear: zero tangents" but smooths; `straightenSpatial` is the linear one.
- `hue_short_delta` uses `x - y * round_ties_even(x / y)` for C `remainder` (exact below |x/y| < 2^44; marked `// shortcut`).

## Not ported
- `KeyframeClipboard`, `KeyframeSummary`, `PropertyTrack`, `EaseSelection` have no serde code: they are never saved (the Swift
  `Codable` conformances are only used by a clipboard round trip test).
- Swift tests left out: `pairsDeclaredForTransformAndReframe`, `transformEffectParamsFollowMotionOrder` (EffectCatalog, M-4),
  `customCurveWithOvershootRoundTripsThroughTheEditorShape` (CubicBezierEase, M-2), HueKeyframeTests parts on color wheels
  and effects, KeyframeEditFollowTests.
