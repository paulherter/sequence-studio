# M-2 notes (animation, effects, fades, graphics logic)

## Done
- `blend_mode.rs`: `ALL`, `title`, `group`, `menu_sections`, `is_legacy`, `minimum_file_version`.
- `track_pan.rs`: `TrackPan` (gains, linear, channel_gains; `MIN/MAX_VOLUME_DB`), `AudioTag::{title, target_lufs}`.
- `curve_math.rs`: `normalized`, `evaluate`, `sample`, `Spline`.
- `affine2.rs`: `rot_scale`, `linear`, `apply`, `after`.
- `clip_animation.rs`: set-or-keyed flags, `anti_flicker_strength_at_local`, `ClipTransform::is_tilted`, `Clip::transform`
  (private 89-degree tilt clamp, same as `PerspectiveTilt.clamped`), `Clip::volume`. Test helper `test_util::clip`.
- `clip_effect.rs`: derived decode now runs `pin_basic_model` (through a private wire struct); all key/kind constants as
  `ClipEffect::*` consts; `new`, `gaussian_sigma`, `rounded_corners`, `key_times`, `frozen_at_local`;
  `EffectColor::{BLACK, WHITE, clamped, rgb}`; `Clip::{effect_of_kind, rounded_corners_effect, set_rounded_corners_effect}`.
- `fades.rs` / `fades_curve.rs`: `FadeKeys` (an uninhabited enum used as a namespace), `FadeMarks::is_empty`, the audio fade
  methods on `Clip`, `Timeline::has_audio_transition`, `FadeCurve`, `DefaultFadeCurve` (key + parse only).
- `motion_easing.rs`: `CubicBezierEase`, `MotionCurve` (raw value = position in `ALL`), custom curve on `ClipEffect`.
- `anchored_animation.rs`: `SegmentShape`, `AnimationTrack`, `AnimationAnchor`, `KeyframeTemplate` (v1 migration,
  looping, retime), `AnimationSet`, `AnimationSample`.
- `graphics.rs`: constructors, lookups, `Clip::{graphics, set_graphics, is_graphics}`, `Project::{graphics_clip,
  contains_graphics_clips}`, the Shape effect keys, `AnimatedProperty::{set_at_local, toggle_keyframing_at_local}`.
- `effect_defaults.rs`: `EffectDefaults` data, lookups, `payload`, `with_fresh_key_ids`, `same_curve`.

## Shortcuts (marked in code)
- `KeyframeTemplate::text_animator` and `EffectDefaults::transitions` are opaque `serde_json::Value`: `TextAnimator`
  (TextAnimatorModel.swift, no task owns it) and `TransitionPreset` (EffectPreset.swift) are not in the crate yet.

## Id sources
Swift `UUID()` inside fade edits, keyframing helpers and `with_fresh_key_ids` is an `&mut dyn IdSource` argument.
`Timeline::normalizeAudioKeyMarks` is `Timeline::audio_key_mark_fixes() -> Vec<Clip>` (it needs `replaceClip`, M-1): the
caller replaces the returned clips.
