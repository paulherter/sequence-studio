## Behavior notes
- `Track`, `Project` and `AudioTrackInfo` read through a private wire struct (`try_from`/`from`) because their Swift
  decoders look at several keys at once. Reading a `Track` with overlapping clips is an error.
- Serde structs also accept a JSON array where Swift's keyed container would throw; only matters for broken files.
- `GraphicsFollow` and `VariantOverride` call `EncodeContext::mark` (edge padding v85, tilt v84) while serializing.
- `VariantOverride::is_empty` and `SourceMarks::is_empty` are public because reading `Project`/`VariantOverrides` uses them.
- The Sequence Volume range (-60 ... 15 dB) is a private const pair in `timeline.rs`; M-2 can point it at `track_pan.rs`.
- `DeliveryTarget` missing-level defaults are -14 LUFS / -1 dB (both Swift loudness groups give these).
