## Deviations to know
- Non-optional keys with an explicit JSON `null` fail in serde where Swift's `decodeIfPresent ?? default` takes the default
  (Swift's encoder never writes such nulls).
- `ClipColor` decodes `effects`, `sections` and the v10 keys together before choosing; Swift reads `sections` only when
  `effects` is absent, so a malformed `sections` next to valid `effects` fails here only.
- The fixture `project-v71.json` holds none of these types; the fixture test only walks it for future content.
