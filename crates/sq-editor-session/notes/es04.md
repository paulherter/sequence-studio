## Deviations
- `ColorClipboard::load_memory` replaces the skeleton's `EditorSession::load_memory` (Swift: `ColorClipboard.loadMemory`).
- Swift default arguments are explicit parameters (`TransitionDefaults`, `ApplyMode`, `duration`, ...); `.shared` singletons
  are plain constructors (`ColorClipboard::new`, `LookStore::new`, `EffectDefaultsLibrary::new`).
- `UserDefaults` -> `SettingsStore` bytes: ints/doubles as decimal text, recents as a JSON array.
- Effect/transition preset items take the id and creation time (Swift made them inside `PresetItem.init`).
- Edit errors reach `last_error` as `EditError`'s `Display` text (ES1's `message_for` wording once merged).
- The app persists `effect_defaults()` itself after a change (Swift `onEffectDefaultsChange` has no event yet).
- Two session tests are `#[ignore]` until ES1 `select` is real (they select the new clip).
