# ES10 notes (workspaces, settings, preferences)

## For the maintainer / other groups
- `MonitorQuality` is ES1's (merged: the ES10 copy is gone). `PixelAspectChoices::items` lives with ES1's type in `es01_session_core/format.rs`.
- `Cargo.toml` gets `serde` and `serde_json` (workspace deps) for the layout/store JSON; other groups may add the same lines.
- `UiDefaults` (sq-uikit) has no bool/double. ES10 stores a flag as the integer 0/1 and a fractional number as text
  (`DefaultsExt`); the app's JSON-file `UiDefaults` must keep that mapping. `ProxySettingsStore` reads the same
  `sq.proxy.export` key through its own `ProxyDefaults::bool`, so the app adapter has to map both to one stored value.
- Paths: `WorkspaceStore`/`FloatingPanelState` take file paths (`default_path(application_support)`); the app owns the folder.
- Platform queries not available portably: free disk space (`StorageLocations::free_bytes` returns `None`, validation then
  passes) and the active keyboard layout (`KeyboardStyle::system` reads `LC_ALL`/`LANG`).
- `StorageLocations::apply_waveform_directory` is a no-op (Swift: only the Mac's waveform disk cache is configurable); the
  library preview cache root is set by whoever builds `PreviewCache` (pass `cache_folder`).
- Swift statics that were mutable globals (`StorageFolderChoice.movesProxiesAtOnce`) are a parameter: `ProxyMove`.
- `UpdateCheck::check` takes the HTTP GET as a closure (`Option<Vec<u8>>`); the app supplies the client.
