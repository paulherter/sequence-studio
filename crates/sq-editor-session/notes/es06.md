## Shape of the async parts (no `await`, no stored session)
- `AnalysisJob` is the state machine (generation, whole-percent progress, cancel ends once, late results ignored).
  `start` hands out an `AnalysisJobCtx` (cancel token + progress reporter).
- `AnalysisFlows` methods take `&mut EditorSession` and an `AnalysisLauncher` (the app: `poster()` into the inbox,
  `launch()` on a `WorkerPool`, with a Send id source). Workers answer with `AnalysisFlowsMessage`; the app calls
  `AnalysisFlows::handle_message`. `setJob`/`flash`/`onStabilizeProgress` are `AnalysisFlowsEvent`s (`take_events`).
- Session methods split the same way: `reframe_run` / `ReframeRun::analyze` (blocking, worker) / `finish_reframe`, and
  `stabilize_run` / `StabilizeRun::analyze` / `finish_stabilize`; `auto_reframe` and `stabilize` chain the three on the
  calling thread (tests, scripts).
- `MagicMaskSession` is a state machine with request objects (`MagicRequest`, `SoftMatteRequest`, `PickRequest`) the host
  runs on workers; `prepare` is one turn of the Swift loop (`PrepareCall` keeps the flags); the watchdog is `expire()`
  on a timer. Needs from the host: the segmenter, `MagicPickMatte` (Swift `MagicMaskTracker.pickMatte`) and a `MatteStoring`.
- `MagicTrackHealthCache` queues `HealthJob`s (`take_jobs`) and takes `HealthResult`s (`finish`).
- Loudness (`measure_loudness*`, `match_loudness`, `voice_chain_readout`) takes a `MeasureLoudness` closure: the app
  renders the one-track sequence it is given (Swift: `TimelineAudioSource` + `LoudnessNormalizer`).
- Voice recording: `VoiceRecorder` trait (the shell's microphone); `VoiceRecordingStep::Started { play }` replaces the
  hidden `playPause()` (the caller plays when `play`). The importer is a blocking closure.
- `AudioExtraction::write` takes the encoder and a closure that builds the mix source; `extract_audio` returns the file for the
  app to import (the `ProjectPanelModel` method has no ES7 type to hang on yet).

## Deviations to know
- `AnalysisFlows::backend` is `Option<Arc<dyn AnalysisBackend>>` (workers need it); `new` still takes a `Box`.
  The `AnalysisBackend` trait lives in `services.rs` (K2): its member tags (`AnalysisFlows.swift:22-26`) sit on
  `NoAnalysisBackend`, the Swift protocol-extension defaults.
- Live ducking reads Preferences through `&dyn DefaultsStore` (`effective_live_ducking(defaults)`, bake functions).
  `SettingsStore` values (silence settings, role defaults, anonymize and reframe picks) are stored as UTF-8 text.
- Private helpers for Swift names owned by other groups, prefixed `es6_`: `es6_attempt`, `es6_perform_timeline`,
  `es6_command_clips`, `es6_active_variant_id`, `es6_with_ids` (ids are parked while `perform` runs), `es6_attempt_ripple`
  (calls ES1's `seek_sequence`), `helpers::timecode`. When ES1/ES2/ES4 land their versions, replace these.
- `DisguiseVoiceCaptions` has a private copy of `CaptionMapping.snapped` (ES5 owns it).
- `bake_*`: the Swift `(silences as? WaveformSilences)?.forExport` unwrap is the caller's job (pass `for_export()`).
- `schedule_stabilizer_replan` reads the cache on the UI thread (shortcut noted at the function).
- `Stabilizer.effect` is `sq_core_effects::effects_editing::stabilizer_effect` (not a `Stabilizer` method in Rust).
