# ES8 notes (es08_media.rs and es08_media/)

All 120 members of ES8 are ported (`scripts/session-tasks.py --stats`: ported 120, pending! 0). 53 tests next to the code
(`cargo test -p sq-editor-session es08`).

## Decision (K2 open point): how an auxiliary engine is shared between the session and the proxy service
The session owns EVERY engine (`engine` and `auxiliary_engines`, boxed). The proxy service holds none (Swift held weak
references). It only records what the monitors must be told, as `ProxyEffect` values (`UseChanged(ProxyUse)`,
`ProxiesChanged(ids)`), read with `AutoProxyService::take_effects()`; the session applies them to the Program engine and
to every alive auxiliary engine (`is_alive`). Nothing is shared, so no `Rc`/`Arc<Mutex>` around engines is needed.
The resolver's own side (`drop_proxies`) is done by the service itself (it holds `Arc<ProjectMediaResolver>`).

## Differences from Swift
- Async parts are `async fn` associated fns over `UiRef<R>` with `R: SessionRoot + MediaWorkers` (the app implements
  `MediaWorkers { workers() -> Arc<WorkerPool> }`); their synchronous halves (`begin_disk_refresh`/`finish_disk_refresh`,
  `apply_disk_changes`, `fold_growing_probes`, `near_project_plan`, ...) are what the tests drive. A dropped
  `refresh_media_from_disk` future leaves `disk_refresh_running` set (no drop guard over the session); the app never cancels it.
- `refresh_media_from_disk` returns after the reopened media were prepared (Swift detached that `Task`).
- `ProjectThumbnails` is a state machine (`take_jobs` / `finish` / `take_arrived`) over a `ThumbnailSource` the app implements
  (ImageIO/FFmpeg); Swift `done` closures became `take_arrived` + `version`. `Thumbnail` is RGBA8 bytes instead of `NSImage`.
- `RenderCacheController`: the 1 s timer is the host's (`tick() -> Option<RenderJob>`, run on a worker, `finish`); hooks are polled
  (`take_spans_changed`, `take_seed_frames`). The default renderer (`RenderCacheSegmentWriter`) is not ported: `render: None`
  never starts a job. Media stamp uses the `Debug` text of `MediaInfo` instead of sorted-key JSON.
- `AutoProxyService` is a state machine too (see its module docs): blocking decisions are `ProxyDecisionWork::run` on a worker,
  transcodes are `take_started_jobs` / `complete_job`. Settings changes call `defaults_changed()` (the host debounces).
- `ProjectMediaResolver`: audio opens need an injected `AudioFactory` (no portable audio opener yet; without it every file is
  "no audio"); stills need a `StillLoader`; no "one open in flight per media" sharing (a racing second open is discarded).
  It also implements `sq_media::MediaOpener` for the engine.
- `HandleProgramEngine` (ProgramEngine over `sq_playback::ProgramHandle`): `scrub_latency_text` is `None` (no summary in
  `PlayStats`), proxies are stored but the render thread opens originals only, `attach` is a no-op (the GPU host draws `latest_shown`).
  Meters/ducking/silences come in through the `EngineAudio` trait.
