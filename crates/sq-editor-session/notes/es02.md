## Deviations / decisions
- `perform_timeline` does not run `normalizeAudioKeyMarks` (no core port yet), same shortcut as ES1.
- `PasteMedia::image_file_name` formats the date in UTC (no local time zone in the portable core).
- `PasteMedia.read(from: NSPasteboard)` is Mac-only and not ported (`PasteContent` is the portable value).
- `offset_split_edit` takes `&AudioRoleDefaults` (ES6) instead of `.load()`; the caller loads the defaults.
- Tests that need `select` / `seek` (ES1, still `pending!`) were not translated: paste at playhead, cut + paste insert,
  select-after-bundle, switch angle. They belong in a follow-up after ES1 merges.
