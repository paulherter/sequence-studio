# ES1 notes (session core rest)

## Still `pending!("ES1")` (the Rust core misses what they call)
- `bleep_range`: `Timeline::bleep` (ToneGenerator.swift) is not ported.
- `group_selection`, `ungroup_selection`, `unnest_selection`: `Project::group / ungroup / unnest` (Grouping.swift) not ported.
- `relink_missing_in`, `missing_siblings`: `RelinkPlanner` (Relink.swift) not in sq-core-project (relink.rs waits for it).

## Not ported on purpose
- `CommandMenuKeys` (AppKit `NSMenuItem`, `NSEvent.ModifierFlags`): Mac menu glue; the key text comes from `sq_uikit::menu_keys`.
- `voiceRecorder` (`#if os(macOS)`), `onChange` (is `Change` + versions), `engine` (K2 getter `engine()`).
- `refresh_missing_shoot_info`: empty (Mac-only metadata read in Swift).

## Shortcuts (each has a `// shortcut:` comment)
- File work (`save`, `save_as`, `save_copy`, `open`, `tick_autosave`, `save_checkpoint`, `recover`, probes) is synchronous on the
  calling thread; the app runs it from a worker job. The autosave and recovery timers are the app's: it calls `tick_autosave` /
  `tick_recovery`. `start_autosave_timer` only stops a stored task.
- Follow selection: the deferred evaluation has no executor handle in the session, so the app pump calls `tick_follow()` when
  `next_follow_deadline()` passes (`follow_task` stays `None`). `mono_now()` is a process-wide monotonic clock.
- `poll_engine_position()` is Swift's `engine.onPositionChange`; the app calls it from its frame pump.
- `TimelineEdit` has no `FastCut(FastCutEdit)` variant until ES3 declares `FastCutEdit`; `delete_selection` calls `magnetic_delete`
  directly in Fast Cut. `MoveCaption` / `TrimCaption` need `CaptionTrack::move/trim` in sq-core-model (refused with ClipNotFound).
- `normalizeAudioKeyMarks` is not in the Rust core: `perform_timeline` skips it.
- `place_media`: the source patch (`patched`) is ignored (no patch state in the session yet).
- `conform_text_block` returns `None` (text layout is not a session dependency); `collectLUTs` on save is not ported (ES4).
- `sync_media` reopens only media whose path moved; pixel aspect / channel map / field order / probe-info redraw come with ES8.
- `play_pause` / `apply_shuttle` skip `engine.clearLookPreview()` (ES4 owns the look preview).
- `set_color_matte_preview` and `open_sequence_tab_variant` stay with ES4.
- `project_did_change` skips `syncStyleKit()` (ES5 adds the call).

## For the maintainer at merge
- ES2 mirrors `message_for`, `perform_timeline`, `attempt`, `attempt_ripple`, `TimelineEdit` (subset), `EdgeSelection`, `EdgeRef`,
  `GapSelection` in `es02_timeline_ops/{attempt,shim}.rs`: delete the mirrors, keep ES1's. `TimelineEdit` here uses struct variants
  with the same names and fields as ES2's subset; `apply` takes an id source: `apply(&self, &mut Timeline, &mut dyn IdSource)`.
- ES2's `playhead_trim_tracks` / `clamp_message` are private duplicates here (`playhead_trim_track_ids`, `clamp_text`); unify later.
- Settings bools (`ToolState` toggles) are stored as the bytes `true` / `false` in `SettingsStore`.
