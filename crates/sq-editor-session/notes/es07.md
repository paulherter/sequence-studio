# ES7 notes (project panel, proxy intake, recents)

Ported: all 206 members of the group (module `src/es07_project_panel/`). No `pending!("ES7")` is left: `import_synced`
(folder sync through `EditorSession::amend_project`, no undo step) and `import_projects` (`Project::merge`) are wired.
- `EditorSession::add_keyword_at_playhead`: wired after ES5 (`generators.rs`).
- `LibraryStores::preset_store` is done; `support_directory` takes the platform Application Support root as a parameter.

Core changes asked for / done outside the module: `Cargo.toml` of the crate gained `sq-text`, `serde`, `serde_json`.

`project_ops.rs` is gone: smart bin verbs and `used_fraction` are `Project` methods in sq-core-model, `SmartBin::matches` is
`SmartBinMatchExt` in sq-core-project, the rest are the ext traits of sq-core-edit and sq-core-audio.

Mapping decisions:
- `ProjectPanelModel` holds its own `Project` copy; edit methods take `session: &mut EditorSession`
  (`commit` = `session.perform`, replacing the session project by the model's copy, as the Swift `onEdit` host did).
  `onCoalescingEdit` is `set_coalescing_imports(bool)` (key `import-N`); `onUnsupported`, `onAudioDropped`, `onImported`
  are `ProjectPanelEvent`s (`take_events`); `projectFolder` is pushed with `set_project_folder`; `amend` is `EditorSession::amend_project`.
- Async import: `ProjectPanelModel::import_files(h: UiRef<R>, urls)` with `R: ProjectPanelRoot` (`panel_parts()` gives model
  and session together). Probes run on the `WorkerPool` through the `ImportBackend` trait (probe, file identity, image
  sequences, failure reason, dropped audio), windowed by `probe_limit`.
- `scheduleOfflineRefresh` runs the stat calls on the calling thread (`shortcut:`).
- Source Timecode column: `cell_text` queues a request; the app reads the file and answers `set_source_timecode`.
- `ProjectMenuContext` carries prebuilt submenu rows (`pixel_aspect_rows`, `audio_channel_rows`) instead of
  `PixelAspectChoices.State` / `AudioChannelMap`, which belong to ES8/ES6 and do not exist yet.
- `ProxyIntake` keeps its state in `Rc<RefCell<..>>` for its `spawn_local` tasks; job end is polled every 100 ms (`shortcut:`).
- Recents, column layout: JSON through `SettingsStore` with the Swift keys; `Date` = `Timestamp` (reference seconds, as
  Swift's default `Date` coding).
