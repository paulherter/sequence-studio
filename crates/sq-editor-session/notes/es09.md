# ES9 notes (Export dialog)

- No stubs-first commit: the module was written complete in one pass (cargo check green, 162/162 members).
- `ExportDialogModel` is one type over `es09_export/{model,model_jobs,session_items}.rs`. Renames: Swift `settings`
  -> `settings()`/`set_settings`, `settings(for:)` -> `settings_for(id)` (the K2 stub had `settings(id)`).
- Swift `async` parts (audio check, stem export) are `begin_*` -> `Request::run(&CancelToken)` (blocking, worker) ->
  `finish_*`; `run_audio_check` / `export_stems` do all three inline. `submit*` return the job ids and do not run the
  queue: the host calls `queue.run_all()` on a worker (Swift `run:` flag dropped).
- `onExportCutDowns` is `on_export_cut_downs()` pushing `ExportDialogEvent::ExportCutDowns` (`take_events`).
- `ExportDialogModel::new` takes `ids: Box<dyn IdSource>` (formats, jobs, saved stem presets) and the free-space probe;
  Swift default `initialPreset = .default` is `Some(ExportPreset::DEFAULT)`.
- `sequence_items` takes the caption-box callback (`EditorSession.captionBox`, not ported yet) as `Option<&CaptionBounds>`;
  every timeline counts as pickable until `Timeline::is_group` exists (shortcut comment in `session_items.rs`).
- `systemFreeSpace` = `ExportPreflight::free_bytes` (None until a platform probe exists); `encoder_speed_hint` takes the
  physical memory as a parameter; the stem encoder has no AVFoundation default (None = "not available").
- `ExportPreflightReport::build` is synchronous (`unreadable_media` is sync in sq-export).
- Not ported: the Swift sheet-level tests that need the app (ExportDialogRound2/StemsChapters bodies beyond the rules
  covered in `es09_export/tests.rs`).
